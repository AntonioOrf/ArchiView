# Allegati

A ogni scheda puoi allegare le riproduzioni del documento: fotografie, scansioni, PDF.

## Aggiungere un allegato

Dall'editor della scheda, nella sezione dedicata agli allegati. I file vengono **copiati** dentro
la cartella `allegati_manoscritti` della tua cartella di lavoro: se in seguito sposti o cancelli
l'originale, la scheda continua a funzionare.

## Visualizzare

Il visore integrato apre immagini e PDF senza uscire dal programma. I comandi:

| Azione | Come |
| --- | --- |
| Ingrandire / ridurre | Rotella del mouse, oppure i tasti <kbd>+</kbd> e <kbd>-</kbd> |
| Spostare l'immagine | Trascinamento col mouse |
| Ruotare di 90 gradi | Tasto <kbd>R</kbd> |
| Adattare alla pagina o alla larghezza | Pulsanti del visore |
| Allegato precedente / successivo | `Alt` + frecce sinistra/destra |
| A schermo intero | `Alt+F` |
| Adatta alla pagina / dimensione reale | `0` / `1` |

Ci sono inoltre i regolatori di **luminosità**, **contrasto** e la modalità **negativo**: sono
pensati per le scritture sbiadite o difficili da decifrare, e a volte fanno emergere un tratto
che a occhio nudo non si legge.

## Consigli sui file

- **Nomi ordinati**: `c001r.jpg`, `c001v.jpg`, `c002r.jpg`. L'ordine alfabetico diventa l'ordine
  delle carte, e con la scorciatoia di scorrimento le sfogli nella sequenza giusta.
- **Un PDF unico o tante immagini?** Il PDF è comodo per un documento già digitalizzato in blocco;
  le singole immagini sono più flessibili se lavori carta per carta.
- **Attenzione allo spazio su disco**: le scansioni ad alta risoluzione occupano molto. Gli
  allegati sono copiati, quindi lo spazio occupato raddoppia rispetto agli originali.

## Riordinare le carte

Le miniature si trascinano per metterle nell'ordine giusto (o si spostano con le frecce, da
tastiera). La trascrizione segue la carta: riordinare non mescola i testi.

## Far leggere il testo all'app

Su scansioni di documenti tardi o a stampa, l'[OCR](/guida/ocr) può riconoscere il testo e
renderlo cercabile senza trascriverlo a mano.
