# Primo avvio

## La cartella di lavoro

Al primo avvio ArchiView chiede di scegliere una **cartella di lavoro** (chiamata anche
*workspace*): è il posto sul tuo disco dove finirà tutto il materiale.

Scegli una cartella vuota, in un percorso che non rischi di cancellare per errore, ad esempio
`Documenti\ArchiView`. Evita cartelle temporanee o il Desktop di un computer condiviso.

Dentro, il programma crea da solo:

- `database_manoscritti.json`: il file con tutte le schede e le trascrizioni;
- `allegati_manoscritti`: la cartella con le immagini e i PDF che allegherai.

::: tip
Se usi già un servizio di backup automatico (cronologia file di Windows, un disco
esterno), fai in modo che copi anche questa cartella. È l'unica cosa da salvare.
:::

Puoi cambiare cartella di lavoro in qualsiasi momento dalle **Impostazioni**.

Puoi rivederla quando vuoi dall'icona **?**.

## Primo modello, prima scheda

Prima di catalogare, ArchiView vuole sapere *che tipo di documento* stai schedando: un'imbreviatura
notarile ha campi diversi da un atto giudiziario. Questa scelta si chiama **modello di documento**.

Puoi partire da uno dei modelli già pronti oppure costruirne uno tuo scegliendo i campi che ti
servono. Vedi [Modelli di documento](/guida/modelli), poi passa a
[Creare e compilare una scheda](/guida/schede).
