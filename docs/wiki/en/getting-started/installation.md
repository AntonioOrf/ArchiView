# Installation

ArchiView is not used from a browser: it is a program you install on your computer. For now it
is available for **Windows** only.

## Downloading the program

1. Open the [releases page](https://github.com/AntonioOrf/ArchiView/releases).
2. Choose the most recent version at the top of the list.
3. Under **Assets**, download the `.exe` file.
4. Run the downloaded file.

## "Windows protected your PC"

On first launch Windows may show a blue SmartScreen warning. It is neither an error nor a virus:
it concerns every program that is not signed with a commercial certificate, which costs several
hundred euros a year and is not sustainable for a free project.

If you downloaded the file from the official releases page, click **More info** and then
**Run anyway**.

## Updates

ArchiView checks for newer versions on its own and tells you when one is available. Updating does
not touch your data: records, transcriptions and attachments stay where they are.

## Uninstalling

Removing the program does **not** delete your archive, which lives in a folder you chose (see
[Where your data is stored](/en/data/storage)). If you want to remove that too, you have to
delete the folder yourself.
